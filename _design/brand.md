# 品牌元素包 · 邻里鲜（临时名）

| 项 | 定义 | 出现在哪 |
|---|---|---|
| Logo | 绿色圆角方块里一个白色屋顶轮廓（小区 / 邻里），屋里一片琥珀色嫩芽（新鲜）。内联 SVG，见 `admin/shell.js` 的 `LOGO` | 后台侧栏、总览页 |
| 记号色 | 琥珀 `--c-mark #A06500`，**只表示「截单 / 时限」**：截单倒计时、售后处理时限、快卖完提示 | 后台顶栏、工作台、团期页、售后页；小程序首页、详情、购物车 |
| 功能记号 | `.mk-pickup` 提货牌：绿色浅底胶囊 + 定位针 + 「明天 16:00 起可提 · 提货点」。代表核心卖点「今天下单，明天到小区自提」，每页至少 1 处 | 小程序首页、详情、购物车、结算、订单、提货码；后台团期页、订单详情 |
| 文字记号 | 价格一律 `.price`：红色、等宽数字、¥ 和角分缩小一号 | 所有价格 |

## 颜色分工（不能混用）

| 颜色 | 值 | 只用在 |
|---|---|---|
| 主色 · 生鲜绿 | `#078149`（白底 4.95:1） | 选中态、主按钮（核销、提交、看提货码）、提货牌、侧栏选中 |
| 价格红 | `#E12A24`（白底 4.61:1） | 价格、优惠金额、优惠券、购物车角标 |
| 行动橙 | `#F14D05` | 只给三个按钮：加入购物车（+）、去结算、微信支付。白字对比 3.62:1，只能用在 ≥16px 粗体上 |
| 记号琥珀 | `#A06500` | 截单倒计时、时限 |
| 深绿 | `#13221A` | 后台侧栏、团长工作台顶部（团长端和居民端靠这个区分） |

色值由 OKLCH 计算：种子 `#12A05C`，按白底对比度二分明度，中性灰混入 2–4% 绿色色相。
