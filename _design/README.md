## 业务规则（原型里体现的，写代码时照这个做）

1. **每日一期**：前一晚 23:00 开团 → 当晚 23:00 截单 → 次日 16:00 起到提货点自提，提货截止为再次日 21:00。时间可以在建团期时改。
2. **截单前**居民可以自己取消订单，全额原路退款；**截单后**只能申请售后。
3. **限购**按「每人每期」计；**库存**按团期单独设，卖完自动显示「已抢光」。
4. **提货码** 6 位数字 + 二维码，团长核销时必须逐件点货，全部点完才能确认交货。
5. **售后**：提货后 24 小时内可申请；平台 24 小时内不处理自动同意退款。审核时选责任方（供应商 / 团长 / 平台 / 物流），用于对账。
6. **优惠**：满减券、折扣券、新人 1 元购；结算时自动选最划算的一张，一单只能用一张。
7. **团长入驻**：后台审核时自动检查 1.5 公里内是否已有提货点、有没有冰柜（没有冰柜的提货点不能卖冷藏商品）。

## 写代码的打算

- **后台**：复制 `D:\JeecgBoot\templates\admin-template`，新增 `views/groupbuy/*` 9 个页面；菜单写进 `sys_permission`。
- **后端**：在 jeecg-boot 里新建模块 `jeecg-module-groupbuy`，表结构见下；截单、自动开团、超时退款用 JeecgBoot 自带的定时任务（Quartz）。
- **小程序**：复制 `D:\JeecgBoot\templates\miniapp-template`（uni-app），按 `mp/` 的 10 页写；微信支付需要你提供商户号，没有之前先用模拟支付。

### 表结构草稿

| 表 | 主要字段 |
|---|---|
| `gb_goods` 商品库 | 名称、规格、类目、采购价、建议价、参考价、供应商、产地、储存方式、状态、图片 |
| `gb_period` 团期 | 名称、开团 / 截单 / 提货 / 提货截止时间、状态、提货点范围 |
| `gb_period_goods` 团品 | 团期、商品、团购价、本期库存、已售、每人限购、上下架 |
| `gb_point` 提货点 / 团长 | 团长、手机、提货点名称、地址、经纬度、营业时间、有无冰柜、覆盖户数、状态、佣金比例（预留） |
| `gb_order` 订单 | 订单号、团期、用户、提货点、商品金额、优惠、实付、状态、提货码、提货时间、留言 |
| `gb_order_item` 订单商品 | 订单、团品、单价、数量、已交付 |
| `gb_aftersale` 售后 | 订单、商品、类型、原因、图片、退款金额、责任方、状态、处理时限、回复 |
| `gb_coupon` / `gb_user_coupon` | 优惠规则、发放量、有效期；用户领取、使用记录 |
| `gb_delivery` 配送 | 团期、提货点、箱数、分拣 / 发车 / 签收时间、短少登记 |

## 设计决策

| 维度 | 取值 | 来源 |
|---|---|---|
| 平台 | PC 后台（1440 宽）+ 微信小程序（375 宽） | 用户原话 |
| 主色 | 生鲜绿 `#078149` | 生鲜 / 社区团购的品类色，OKLCH 品牌化 |
| 交易色 | 价格红 `#E12A24`、行动橙 `#F14D05` | 电商惯例：红只给价格，橙只给下单按钮 |
| 间距 | 后台页面左右 24，小程序 16 | 标准档 |
| 字体 | 系统中文字体栈，标题 600 / 700 | 中文在 Windows 上 500 会变常规体 |
| 图标 | 内联线性 SVG（落代码：后台 @ant-design/icons-vue，小程序 wot-design-uni 的 wd-icon） | |
